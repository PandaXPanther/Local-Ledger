# Contributing

Thanks for helping improve LocalLedger.

## Development Setup

```bash
pnpm install
pnpm data:fetch
pnpm data:validate
pnpm data:sanity
pnpm dev
```

## Pull Request Checklist

- Keep every displayed metric tied to source metadata.
- Do not add mock, fabricated, or AI generated data values.
- Run `pnpm typecheck`, `pnpm lint`, `pnpm test`, and `pnpm build`.
- Update methodology or source documentation when formulas or data sources change.
- Keep secrets out of the repository.

## Data Changes

Processed data is generated by `scripts/fetch-data.ts`. Prefer changing the pipeline over hand editing generated JSON.

If a source value is missing, represent it as unavailable with a reason. Do not estimate values unless the methodology explicitly defines a computed metric.
